## 🛠️ How Each Achievement Works

### 1. ⚡ Quickdraw
Awarded when an author closes an issue or pull request within 5 minutes of its creation.

### 2. 🦈 Pull Shark
Awarded for opening pull requests that get merged into the default branch of a repository.
- **Bronze (x1)**: 2 PRs
- **Silver (x2)**: 16 PRs
- **Gold (x3)**: 128 PRs

### 3. 👯 Pair Extraordinaire
Awarded for co-authoring commits on merged pull requests using the `Co-authored-by` Git trailer.
- **Bronze (x1)**: 1 co-authored PR
- **Silver (x2)**: 10 co-authored PRs
- **Gold (x3)**: 24 co-authored PRs

### 4. 🚀 YOLO
Awarded for merging a pull request without waiting for or requiring code review.

### 5. 🧠 Galaxy Brain
Awarded for providing helpful answers in GitHub Discussions (Q&A category) that get marked as the accepted solution by the question author or maintainers.
- **Tiers**: 2, 8, 16, 32 accepted answers.

### 6. ⭐ Starstruck
Awarded when your repository reaches community star milestones.
- **Bronze**: 16 stars
- **Silver**: 128 stars
- **Gold**: 512 stars
